# SINAX UI & Design Guidelines
## إرشادات التصميم والواجهات التفاعلية لمنظومة SINAX

دليل شامل للمعايير البصرية، وتجربة الاستخدام (UX)، وقواعد الخطوط، ودعم اللغة العربية (RTL)، والاستثناءات التقنية (LTR).

---

## 1. فلسفة التصميم (Design Philosophy)

* **الهدوء البصري والمظهر غير المحاط (Border-free Aesthetic)**:
  * الابتعاد التام عن الحدود السميكة والمربعات الرمادية الداكنة ذات الحواف الحادة.
  * الاعتماد على تدرجات الأسطح الناعمة (`surface` و `surfaceHover`) والفراغات المدروسة لصناعة العمق البصري.
  * استخدام حدود دقيقة وشبه شفافة (`borderSubtle`) فقط عند الحاجة لتحديد الحاويات.
* **الأداء الخاطف وسرعة الاستجابة**:
  * زمن ظهور الهيكل الأولي للصفحة (`Time to Page Shell`) يجب ألا يتجاوز **150 ملي ثانية**.
  * زمن استجابة النقرات والتنقل لا يتجاوز **16 ملي ثانية** (60 إطاراً بالثانية).

## 3. قواعد الاتجاه: العربية (RTL) والاستثناءات التقنية (LTR)

### القاعدة العامة (RTL First):
* واجهة التطبيق كاملة مصممة من اليمين إلى اليسار تلقائياً (`Qt.RightToLeft`).
* العناوين، والشروحات، والفقرات، وأزرار الإجراءات تبدأ من اليمين.
* محاذاة النصوص الافتراضية تكون: `horizontalAlignment: Text.AlignRight`.

### استثناءات النصوص والمصطلحات التقنية (LTR Enforcement):
توجد عناصر ومعلومات تقنية **يجب** دائماً عرضها من اليسار لليمين وبخط أحادي المسافة (`Monospace`) لمنع تشوه المسارات أو الحسابات:
1. **مسارات الملفات والمجلدات**: مثل `C:\Program Files\SINAX\app.exe`.
2. **عناوين الشبكة والبروتوكولات**: مثل `192.168.1.1` أو `https://sinax.local:8080`.
3. **التجزئة الرقمية وبصمات الأمان**: مثل `SHA-256: e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`.
4. **أوامر الطرفية والمعاملات**: مثل `SINAX.exe --safe-ui`.
5. **معدلات القياس والأداء**: مثل `60.0 FPS`, `124.5 MB/s`, `48000 Hz / 24-bit`.

**نموذج تطبيقي:**
```qml
Text {
    text: "C:\\Users\\User\\Documents\\report.pdf"
    font.family: "Consolas, monospace"
    horizontalAlignment: Text.AlignLeft
    LayoutMirroring.enabled: false
}
```

## 4. الحركات التفاعلية الدقيقة (Micro-Interactions & Transitions)

* مدة الحركات القياسية تتراوح بين **150 إلى 250 ملي ثانية**:
  ```qml
  Behavior on color {
      ColorAnimation { duration: Theme.animDurationFast; easing.type: Easing.OutCubic }
  }
  ```
* ردود أفعال واضحة لمرور الفأرة (Hover States) والضغط (Pressed States).
* مؤشرات التحميل والتقدم (`SinaxProgressBar`, `isLoading`) في أي عملية تتطلب أكثر من 100 ملي ثانية.
* شاشات فارغة تفاعلية (`SinaxEmptyState`) توضح للمستخدم الخطوة التالية بدلاً من ترك المساحات مهجورة.

## 5. معايير صارمة لهندسة السمات (Theme Strictness & Multi-Theme Architecture)

يخضع نظام السمات في SINAX لقواعد معمارية صارمة تضمن الاتساق التام بين أنماط `System` و `Light` و `Dark`:

1. **حظر تثبيت ألوان الأسطح يدويًا (Never Hardcode Theme Surface Colors)**:
   * يُمنع منعًا باتًا كتابة أكواد ألوان صلبة مثل `background-color: #1E1E1E;` أو `color: #FFFFFF;` في ملفات Python أو QML للأدوات والكروت.
   * في QML: يجب الاعتماد دائمًا على `Theme.surface`، `Theme.textPrimary`، `Theme.borderSubtle`، وغيرها من الرموز الدلالية.
2. **ربط أدوات Qt القديمة (Legacy Qt Widgets Integration)**:
   * جميع صفحات وأدوات Qt Widgets يجب أن تستمد أنماطها من ملفات التنسيق المركزية (`dark.qss` و `light.qss`) أو ترتبط بإشارة `theme_manager.theme_changed` لتطبيق `apply_theme(theme_name)`.
3. **تحديث الصفحات المخزنة مؤقتًا (Cached Pages Theme Response)**:
   * الصفحات الموجودة في ذاكرة التخزين المؤقت (`_loaded_pages`) لا تحتفظ بنمط قديم عند تبديل السمة؛ بل تستجيب فورًا لإشارة `theme_changed` وتحدث واجهاتها قبل عرضها للمستخدم مجددًا.
4. **تطبيق السمة فور التحميل الكسول (Zero Theme Flash on Lazy Loading)**:
   * عند إنشاء أي صفحة كسولة لأول مرة، يمرر لها `theme_manager.effective_theme` فورًا من أول إطار مرئي لمنع حدوث وميض لوني (No Flash).
5. **استثناءات ألوان المعاينة الفنية (Intentional Preview Colors Only)**:
   * يُسمح فقط بتثبيت ألوان مستندات المحتوى الحقيقية (مثل ورقة PDF البيضاء أو كانفاس الصور) عندما تكون جزءًا أصيلًا من معاينة الملف وليست من أسطح التطبيق.
6. **الأوضاع الثلاثة المعتمدة**:
   * **System**: يتبع إعدادات سمة Windows تلقائيًا وبصورة حية لحظة تغييرها دون إعادة تشغيل التطبيق.
   * **Light**: تطبيق ناصع ومريح خالي تمامًا من أي جزر سوداء أو كروت مظلمة شاذة.
   * **Dark**: تصميم داكن راقٍ ومتناسق خالي تمامًا من أي مساحات أو كروت بيضاء فاقعة.
