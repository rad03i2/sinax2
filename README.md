# SINAX | ساينكس
### نظام إدارة الحاسوب والملفات المتكامل لنظام Windows (الإصدار 1.0)

برنامج مكتبي احترافي متكامل مبني باستخدام **Python** و **PySide6 (Qt6)**، مصمم لتقديم تجربة فائقة السلاسة والأمان والسرعة في إدارة وتنظيم الحاسوب والملفات، بواجهة عربية أصيلة بدعم RTL كامل وتصميم حديث مستوحى من Windows 11 Fluent Design.

---

## 🌟 مميزات المرحلة الأولى (File Management - Batch Rename)

1. **معمارية برمجية قابلة للتوسع (Clean Architecture)**:
   - فصل تام بين منطق المعالجة (Services)، والواجهات (UI)، وخيوط المعالجة الخلفية (Workers)، والنماذج (Models).
   - واجهات جاهزة للمراحل القادمة (الدمج، التنظيم الذكي، التحليل والبحث، كشف التكرار).
2. **واجهة مستخدم حديثة وسلسة (Windows 11 Fluent UI)**:
   - دعم الوضعين: **الداكن (Dark Theme)** و **الفاتح (Light Theme)** مع التبديل الفوري وحفظ التفضيلات.
   - شريط جانبي تفاعلي، شريط علوي مع زر رجوع وتنقل ديناميكي، وشريط حالة مع Progress Bar للعمليات الطويلة.
   - دعم السحب والإفلات (Drag & Drop) للمجلدات والملفات من Windows Explorer مباشرة.
   - تمرير مرن وكامل لجميع الصفحات (Responsive QScrollArea) دون أي قص أو تداخل في العناصر.
3. **أداة إعادة تسمية الملفات الجماعية الاحترافية (Batch Rename Tool)**:
   - **فحص ذكي وسريع**: تصنيف فوري للملفات إلى (PDF، صور، فيديو، صوتيات، Word، Excel، عروض، مضغوطة، نصوص، أخرى).
   - **جدول افتراضي عالي الأداء (Virtualized QTableView)**: يدعم آلاف وعشرات آلاف الملفات دون أي تجميد للواجهة.
   - **أكثر من 160 نمطاً جاهزاً (Presets)**: مقسمة ومصنفة إلى 8 فئات قابلة للبحث والتطبيق بنقرة واحدة.
   - **أنظمة ترقيم متعددة وشاملة**:
     - أرقام غربية: `1, 2, 3...`
     - أرقام مشرقية عربية: `١, ٢, ٣...`
     - أبجدية عربية: `أ, ب, ج, د...`
     - أعداد لفظية عربية: `الأول, الثاني, الثالث...`
     - حروف إنجليزية: `A, B, C...` و `a, b, c...`
     - أعداد لفظية إنجليزية: `First, Second...`
     - التحكم في بداية الترقيم وعدد الخانات (`01`, `001`, `0001`).
   - **تعديلات متقدمة**: بادئة (Prefix)، لاحقة (Suffix)، استبدال نصوص (Find & Replace)، حذف نصوص، وتغيير حالة الأحرف.
   - **إدراج التواريخ**: تاريخ التعديل، الإنشاء، أو تاريخ اليوم الحالي.
   - **معاينة حية وفورية (Live Preview)**: عرض الاسم الحالي والجديد وتلوين الملفات المعدلة بالأخضر والمتعارضة بالأحمر.
4. **الأمان الفائق ومنع فقدان الملفات (Bulletproof Safety)**:
   - **فحص التعارضات في الذاكرة**: منع الأسماء المكررة، منع الكتابة فوق ملفات موجودة، وحظر أحرف Windows الممنوعة (`< > : " / \ | ? *`).
   - **محرك إعادة التسمية ثنائي المراحل (Two-Pass Execution)**: حل مشكلة التعارض الدائري وتبادل الأسماء (A -> B و B -> A) عبر أسماء مؤقتة آمنة دون أي فقدان للملفات.
   - **حماية مجلدات النظام**: تنبيهات عند التعامل مع مجلدات Windows و Program Files و System32.
   - **خيوط معالجة مستقلة (QThread)**: تمنع تجميد الواجهة مع إمكانية إلغاء العملية بأمان في أي لحظة.
5. **نظام التراجع الكامل وسجل العمليات (Undo & History)**:
   - تسجيل كامل لجميع العمليات في `history.json` مع الوقت والتاريخ وتفاصيل الملفات.
   - زر التراجع عن آخر عملية (Undo) لاستعادة أسماء الملفات السابقة بنقرة واحدة.

│       │   ├── file_manager_page.py # مركز إدارة الملفات (البطاقات الخمس)

## 🚀 طريقة التثبيت والتشغيل

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

المكتبات المطلوبة:
- `PySide6` (الواجهة الرسومية الحديثة)
- `Send2Trash` (الحذف الآمن إلى سلة محذوفات ويندوز)
- `pypdf`, `python-docx`, `openpyxl`, `Pillow`, `ImageHash` (للمراحل القادمة)

### 2. تشغيل البرنامج:
```bash
python main.py
```

## 🧪 تشغيل الاختبارات الآلية
للتحقق من سلامة كافة خوارزميات التسمية والترقيم والفرز والتراجع وتوافق الواجهة:

## 📦 تحويل البرنامج إلى ملف تنفيذي مستقل (EXE) عبر PyInstaller

يمكن تحويل البرنامج مباشرة وبكل سهولة إلى تطبيق Windows تنفيذي (`SINAX.exe`):

```bash
pyinstaller --noconsole --onefile --name="SINAX" --add-data "app/resources/presets;app/resources/presets" --add-data "app/ui/themes;app/ui/themes" main.py
```
